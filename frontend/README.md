# PRISM Frontend

React + TypeScript + Vite frontend for the PRISM disaster operations dashboard.

## Stack

- React
- TypeScript
- Vite
- MapLibre GL JS
- PMTiles
- GeoJSON
- Framer Motion
- Lucide
- ECharts

## Quickstart

```bash
cd frontend
npm install
npm run dev
```

## Notes

- The frontend is scaffolded and pending integration with the backend API.
- Backend runs on `http://localhost:8000` by default.
- See `../MVP.md` for the API contract and `../AGENTS.md` for project rules.
